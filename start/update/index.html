Update or remove an add-on

Update

Section titled “Update”
  1. Unzip the new zip into the AddOns folder, the same way you installed it. Say yes when it asks to replace the old files.
  2. Type /reload in game, or start the game.

Your settings, your macros, your prices and what PlanWonk learned about your characters are kept: they’re saved apart from the add-on itself.

Update with the manager (planned)

Section titled “Update with the manager (planned)”

Planned, not available yet

The planned manager app will update in one click, back up your saved data first, let you go back to the version before, and tell you when an update is out. It will never be required.

Remove

Section titled “Remove”
  • For a while: on the character screen, click AddOns and untick it. Tick it again to have it back as it was.
  • For good: close the game and delete its folder from the AddOns folder. Its saved data stays, so a later install picks up where you left off. To clear that too, see Details.

If something broke after an update, see Troubleshooting.

Details

Section titled “Details”
  • The AddOns folder: World of Warcraft/_forever_/Interface/AddOns/. Replace MarketWonk and MarketWonkData together.
  • Check the version: /wonk plan state names PlanWonk’s build; MacroWonk says Build X. at login when it changed; /wmd names MarketWonkData’s.
  • The saved data is in World of Warcraft/_forever_/WTF/Account/<account>/SavedVariables/, one file per add-on (PlanWonk.lua, MacroWonk.lua, MarketWonk.lua, MarketWonkData.lua, TheoryWonk.lua). MacroWonk also keeps one per character, under WTF/Account/<account>/<realm>/<character>/SavedVariables/. Deleting an add-on’s files there (with the game closed) clears what it remembered. Keep a copy first: Back up or move to a new PC.
