Commands

Every command starts with /wonk plan. /wonk plan help lists the top-level ones in game, and /wonk plan plan help lists what changes the plan. Most settings say their current value when you give none: /wonk plan plan ah answers auction house on.

Windows

Section titled “Windows”
Command What it does
/wonk plan Show or hide the window
/wonk plan min Minimize the window to its title bar
/wonk plan plan The full plan (the Plan view’s Professions tab)
/wonk plan goals The Goals page: professions in or out, targets, goals
/wonk plan options (or /wonk plan settings) The settings window
/wonk plan guide [<n>] Open the window in the Guide view, naming n goals: the current one, then the rest on its then: line (2 at first)
/wonk plan guide why The current step’s reason under it, or only on hover
/wonk plan guide hold now|next <seconds|Nm|never|default> How much faster a new order must be to change the card you’re on (now) or what’s next on screen (next)
/wonk plan guide lock Lock or unlock the window (the same as /wonk plan settings lock)
/wonk plan next <n> How many of the plan’s next steps the route holds still in the Plan view (3 at first; 0: the minimized title shows the first leveling or profession step)

The leveling route

Section titled “The leveling route”
Command What it does
/wonk plan route The route’s hubs from where you are: level, time and quests each, and the time left
/wonk plan route all Every hub, the done ones too
/wonk plan talents Your talent build to 60 for your spec: the next points, each tree’s points by level, and a reset when one pays
/wonk plan talents spec <spec>|auto · keep · show · resets on|off Plan toward a spec (or the tree your points are in) · keep your talents, no resets until the spec changes · show resets again · suggest resets or not

The arrow

Section titled “The arrow”
Command What it does
/wonk plan arrow on|off Show or hide the arrow
/wonk plan settings arrow own|tomtom|auto PlanWonk’s arrow, TomTom’s, or TomTom’s when it’s installed
/wonk plan settings arrow size <0.5-3> How big PlanWonk’s arrow is
/wonk plan settings arrow lock on|off Stop the arrow being dragged
/wonk plan settings arrow minimap on|off Pin where the arrow points on the minimap (on by default)

The tracker

Section titled “The tracker”
Command What it does
/wonk plan settings lock on|off Lock the tracker in place
/wonk plan settings start guide|plan The view the window opens in when you log in (Guide by default)
/wonk plan settings hints on|off The blue hints in the Guide’s live lines (on by default)
/wonk plan settings height <100-1200> How tall it grows before it scrolls
/wonk plan settings height fit Fit what’s shown again, after you dragged its corner
/wonk plan settings gather detail on|off The “as you go” line in full or short
/wonk plan settings autoquest on|off Accept and hand in the plan’s quests (on by default; hold Shift as the window opens to skip one)
/wonk plan settings bagicons on|off A mark on each bag item for its best action: upgrade, set, keep, disenchant, AH or vendor (on by default)

Steps

Section titled “Steps”
Command What it does
/wonk plan skip Skip the first step shown
/wonk plan skip <quest> hard [note] Skip a quest as too hard (by name or ID; /wonk plan skip hard: the first quest shown) and keep what it was, with your note
/wonk plan plan unskip Bring back every skipped step
/wonk plan npc The NPCs you couldn’t find (from a buy step’s menu), numbered
/wonk plan npc clear <n>|all Bring one, or all of them, back into the plan
/wonk plan item The materials you can’t get (from a profession step’s menu: I can’t get this), numbered
/wonk plan item clear <n>|all Bring one, or all of them, back into the plan
/wonk plan defer Hold back the first turn-in shown
/wonk plan undefer Release every held turn-in
/wonk plan replan Plan again now

What the plan aims at

Section titled “What the plan aims at”
Command What it does
/wonk plan plan target <profession> <1-300>|default How far to take a profession
/wonk plan plan hide <profession>|leveling Leave a profession out of the plan, or hide leveling from view
/wonk plan plan show <profession>|leveling|all Put them back
/wonk plan plan future <profession> Plan a profession to learn later, and stockpile for it
/wonk plan plan future off <profession> Stop planning it
/wonk plan plan future List the professions planned for later
/wonk plan plan group on|off Plan Tailoring and Enchanting together
/wonk plan plan ah on|off Use the auction house or not
/wonk plan plan solo on|off Plan this character on its own: alts send nothing, craft nothing for it, and fund nothing (off by default)
/wonk plan plan farm low|normal|high Farm instead of buying: how readily
/wonk plan plan include [<quest>] Opt a dungeon or elite quest in your log into the route (alone: lists them)
/wonk plan plan exclude <quest> Take it back out

Goals

Section titled “Goals”
Command What it does
/wonk plan plan goal skill <profession> <skill> <level> A skill by a level
/wonk plan plan goal item <item> <level> [buy|craft] An item by a level (an ID or a link)
/wonk plan plan goal wands The Enchanting wands, each at its level
/wonk plan plan goal dungeon <name> A dungeon’s quests in your log before you go in
/wonk plan plan goal list List your goals
/wonk plan plan goal clear <n>|all Remove one, or all

Gear

Section titled “Gear”
Command What it does
/wonk plan plan spec Your class’s ratings and your equipment sets
/wonk plan plan spec main <spec> Which rating comes first
/wonk plan plan spec enable|disable <spec> Rate gear for a spec or not
/wonk plan plan spec new <name> [from <spec>] Your own rating
/wonk plan plan spec delete <name> Delete one of yours
/wonk plan plan spec set <set name> <spec|none> Which rating an equipment set is for
/wonk plan plan spec import <Pawn scale> A rating from a Pawn scale string
/wonk plan plan spec value best|<spec> <weight> How upgrades count over your specs: the best one’s (default), or weighted
/wonk plan plan weights [<spec>] <stat> <n> Change one stat’s weight (str, agi, sta, int, spi, ap, fap, sp, dmg, heal, dps, ranged, armor)
/wonk plan plan weights [<spec>] reset [all] Undo your weights
/wonk plan plan upgrades on|off Let your professions plan crafts that are upgrades for you
/wonk plan plan upgrades detour <minutes> Gear upgrades: minutes per 1% better (0 turns it off)
/wonk plan plan travel deathskips on|off Death skips as travel (off unless you turn it on; on isn’t built yet, so the plan never uses one)

Your other characters

Section titled “Your other characters”
Command What it does
/wonk plan plan request list Craft requests between this character and the others
/wonk plan plan request cancel <n>|all Cancel one, or all
/wonk plan partner share [<name>] Share your recipes with a duo partner (your target without a name). Not yet seen in play
/wonk plan partner list Your duo partners, their recipes, whether you always accept their requests, and when each was last heard from
/wonk plan partner accept <name> always Accept that partner’s requests as they come, until you change it. Not yet seen in play
/wonk plan partner accept <name> ask Ask each time again (every partner starts here)
/wonk plan partner forget <name> Forget a partner: their record and open requests go, and nothing is sent to them

Learning, the route, and help

Section titled “Learning, the route, and help”
Command What it does
/wonk plan settings learn What PlanWonk learns as you play
/wonk plan settings learn <discounts|stock|flights|offers|earnings|groupchat> on|off Turn one off (and forget it) or on
/wonk plan rares The rares seen this session, the ones you ignored, and whether SilverDragon is hooked
/wonk plan rares unignore <n>|all Take a rare off your Ignore list (the number from /wonk plan rares)
/wonk plan settings whisper send on|off A click on a nearby player’s name sends the ask (on), or opens it for you to edit and send with Enter (off, the default)
/wonk plan plan route The quest route’s state
/wonk plan plan route on|off Route quests, or plan from the quest log only
/wonk plan plan route effort combat|normal|idle off|low|medium|high The route’s quality: how hard it works on the route
/wonk plan help The top-level commands, in chat
/wonk plan plan help The commands that change the plan, in chat
/wonk plan logout What to do before logging out
/wonk plan bug [<text>], /wonk plan idea [<text>] Save a report
/wonk plan path [upstairs|below|blocked|arrow|other [<note>]] Report the way to the arrow’s target (alone: the arrow’s menu)
/wonk plan state What PlanWonk has read about this character, the build it’s running, the coin and the XP an hour of play brings (measured, or the estimate), your gear against your level’s and what it does to kill time, and the quests marked too hard
/wonk plan reset character [confirm] Forget this character’s saved data and start over
/wonk plan debug Debug output on or off
/wonk plan perf Where PlanWonk’s time goes since the last /wonk plan perf: the costliest events and jobs in ms a second, with the worst call in the last minute; the last plan update’s time and how many this session; its caches’ sizes; its memory and how fast it grows
