Troubleshooting

Find the message you saw; each says what it means and what to do. The messages are quoted as the game shows them.

“3 macros still need you (/mw)”

Section titled ““3 macros still need you (/mw)””

That many macros are waiting for a choice from you. Open the window: they’re the ones with a word beside them. Hover the word for what to do.

“6 macros of your own aren’t shared with your other characters yet: /mw ui, then Save all new shares them”

Section titled ““6 macros of your own aren’t shared with your other characters yet: /mw ui, then Save all new shares them””

Nothing is wrong. To share them, open the window, pick your class and click Save all new.

“Not while shapeshifted: macros change once you’re back in caster form.”

Section titled ““Not while shapeshifted: macros change once you’re back in caster form.””

Macros never change in a form. Leave the form, and what was due happens once.

A macro says held back

Section titled “A macro says held back”

The shared copy now has a lower version than the one you have, for example one that waits for a spell this character hasn’t learned. Click Update in the window to take it. With the setting Update by itself on (on for a new install, off for one already in use), the next update after login takes it without a click.

A macro says no room or error

Section titled “A macro says no room or error”

This character’s macro list is full. Delete a macro in the game’s macro window, then click Update. Another error: the game refused the change, and the line beside it says why.

“Macro list not loaded yet; try again.”

Section titled ““Macro list not loaded yet; try again.””

Right after logging in, the game’s macro list isn’t always loaded. MacroWonk tries again by itself; if the message stays, click Update.

“No character macros found yet. Deleted them all? Type /mw update.”

Section titled ““No character macros found yet. Deleted them all? Type /mw update.””

The list came back empty. If you did delete them all, click Update to get the shared ones back.

“WoW is running: close it to save.”

Section titled ““WoW is running: close it to save.””

The offline editor can’t save while the game runs, because the game would write over it when you log out. Close the game, then save.

“Hit an error · /mw copy has it for a report”

Section titled ““Hit an error · /mw copy has it for a report””

Something went wrong. Type /mw copy to get the details to send. See reporting a problem.

“Library: empty · /mw ui, then Save all new saves your macros · or /mw import an export.”

Section titled ““Library: empty · /mw ui, then Save all new saves your macros · or /mw import an export.””

A first login, with nothing shared yet. Open the window, pick your class and click Save all new.

“From the editor (2): …”

Section titled ““From the editor (2): …””

Things you set up in the offline editor for this character happened at this login. The line says what each one did.

“Same name as a general macro, both kept: Heal”

Section titled ““Same name as a general macro, both kept: Heal””

You have a general macro (the General tab) with the same name as a shared one. Both stay. Rename one if the two are confusing.

Something else

Section titled “Something else”

See troubleshooting for the add-ons in general.

Details

Section titled “Details”
  • Commands: /mw lists what needs you, with what each one needs; /mw update is the window’s Update; /mw save --new is Save all new, at level 1. (/mw sync and /mw commit do the same.)
  • The Advanced view words the buttons as directions: Update is Library -> This character, Save all new is All new -> Library. See the window.
  • Retries: after “Macro list not loaded yet”, it tries again 5 times, 2 seconds apart.
  • The status words are explained on status words.
  • Where things are kept: see backups and undo for the saved file and the backup folders.
